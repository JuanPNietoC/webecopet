# 🐸 EcoPet Web & Portal de Descarga

Sitio web oficial y portal de descarga para **EcoPet**, la experiencia interactiva móvil diseñada desde la **Ingeniería Multimedia** que fusiona:
- 🎨 **Arte Visual & Perspectiva Isométrica 3/4** con calibración anatómica angular.
- 🎮 **Gamificación & Mecánicas Tamagotchi** (Salud, Experiencia, EcoCoins, Gacha).
- 🧠 **Visión Artificial Edge AI** (Ensamble jerárquico de 2 CNNs optimizadas en TensorFlow Lite, 100% offline).
- 📱 **Ingeniería Nativa Android** (Kotlin, CameraX, Drag & Drop).

---

## 🚀 Despliegue en Vercel

Este proyecto está construido con **Vite + React + Tailwind CSS**, listo para desplegarse automáticamente en Vercel:

1. Conecta tu repositorio `JuanPNietoC/webecopet` en [Vercel](https://vercel.com).
2. Vercel detectará la configuración automáticamente:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
3. Presiona **Deploy** y tu sitio estará en vivo en segundos con el APK listo para descarga directa.

---

## 🛠️ Desarrollo Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
